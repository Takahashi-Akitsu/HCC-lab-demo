# HCC Lab Demo

### 📖 项目简介
这是 [数学分析作业:AI小作业1_在创造中学习] 的一个演示项目。本项目主要用于 [练习用AI创造一个新的游戏章节]，关于俺感兴趣的"HBV感染-肝硬化-肝癌"问题]。

### ✨ 功能特点
1.模拟实验设计,紧张刺激的调参环节！（似乎有故意压分的设计嘿嘿）
2.用小人动画显示实验得分（古法板绘注意www自推友情出镜)
3.模拟实验完成后的思考与答题（too simple）

### 🛠️ 本地运行方法
1. 下载或克隆本项目到本地。
2. 双击打开 `index.html` 文件，即可在浏览器中正常运行。
3. 如果需要无角色小人版，请下载`no-character.html`

### 📁 项目结构
*   `index.html` - 主页面入口
*   带`js`后缀的文件 - JavaScript 核心逻辑代码
*   `assets/` - 图片、图标等静态资源文件
*   `styles.css` - 页面样式表
